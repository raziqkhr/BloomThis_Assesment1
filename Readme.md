# Software Developer Intern - Take-Home Assessment

## Git Workflow Commands Used
1. 'git init' - Initialized the local repository.
2. 'git checkout -b feature/assessment-answers' - Create a new branch called 'feature/assessment-answers'.
3. 'git add .' - Staged the Java script, SQL file, and README for commit.
4. 'git commit -m "feat: add data aggregation script and relational SQL query" ' - Commit coding script and SQL text file with clear, descriptive commit messages.
5. 'git remote add origin https://github.com/raziqkhr/BloomThis_Assesment1.git' - Linked the local repo to the public GitHub repository.
6. 'git push -u origin feature/assessment-answer' - Push the repository to a public GitHub.
