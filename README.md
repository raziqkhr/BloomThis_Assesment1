#  Assessment

## Git Workflow Commands Used
1. 'git init' - Used to initialized the local repository.
2. 'git checkout -b feature/assessment-answers' - Used to created and switched to the required branch.
3. 'git add .' - Staged the Java script, SQL file, and README for commit.
4. 'git commit -m "feat: add data aggregation script and relational SQL query" ' - To committ the files with a descriptive message.
5. 'git remote add origin https://github.com/raziqkhr/BloomThis_Assesment1.git' - Linked the local repo to the public GitHub repository.
6. 'git push -u origin feature/assessment-answers' - Pushed the branch to GitHub.
